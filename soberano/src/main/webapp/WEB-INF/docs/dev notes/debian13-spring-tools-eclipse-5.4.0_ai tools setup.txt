OLlama with small local model
=============================

1) In Terminal, install ollama:

	curl -fsSL https://ollama.com/install.sh | sh
	
2) In Terminal, pull the model:

	ollama pull qwen2.5-coder:1.5b
	
3) In Terminal verify ollama actually sees your model:

	ollama list
	curl http://localhost:11434/api/tags

4) In Eclipse, go to Help → Install New Software...

	Click Add...
	
	Enter Name: EclipseLlama
	
	Enter Location: https://vijaytank.github.io/eclipsellama/updatesite/
	
	Click Add, select EclipseLlama, and follow the wizard to restart Eclipse.
	
5) After restarting, open the configuration panel:

    Go to Window → Preferences → EclipseLlama.

    Ollama endpoint URL: Set it to http://localhost:11434 (the default).

	Default model: Select or type qwen2.5-coder:1.5b as your model. This is critical—do not leave it at the default codellama, which is too large for your RAM.

	Settings are stored in ~/.eclipsellama/config.properties if you prefer to edit them manually.

6) In Eclipse, go to Help > Install New Software...

	Click Add... and use the following update site URL:	https://sterlp.github.io/eclipse-peon-ai/

	Select Eclipse Peon AI from the list, complete the wizard, and restart Eclipse when prompted.

	After restarting, open the tool window: Window > Show View > ..., search for "AI Peon", and open it.
	
7) Connect Peon AI to Your Local Qwen Model. In Eclipse:

    Go to Window > Preferences > AI Peon.

    Set the connection details exactly as follows:

    	Provider: OLLAMA

    	Model: qwen2.5-coder:1.5b (or simply qwen2.5-coder)

    	Base URL: http://localhost:11434

    	API Key: Leave it empty.


ZK Docs as context, locally
===========================

1) Install and Initialize the ZK Doc MCP Server:

	curl -LsSf https://astral.sh/uv/install.sh | sh
	
	source "$HOME/.local/bin/env"
	
	uv venv --python 3.10
	
	source .venv/bin/activate
	
	uv pip install zk-doc-mcp-server
	
2) Clone the ZK documentation repo:

	sudo apt update
	
	sudo apt install -y git

	git clone --depth 1 https://github.com/zkoss/zkdoc.git ~/.zk-doc-mcp/repo
	
3) Create a small script, e.g. ~/run-zk-mcp.sh:

		nano ~/run-zk-mcp.sh
		
			#!/bin/bash
			export ZK_MCP_USE_GIT=false
			export ZK_MCP_SRC_DIR="/root/.zk-doc-mcp/repo"
			export FASTMCP_SHOW_SERVER_BANNER=false
			export FASTMCP_SHOW_BANNER=false
			export PYTHONWARNINGS=ignore
			exec uvx zk-doc-mcp-server
			
		chmod +x ~/run-zk-mcp.sh
		
4) Pre-index ZK Docs:
 
 	In Terminal,
 	
 		ZK_MCP_USE_GIT=false uvx zk-doc-mcp-server init
 		
 	This could take long.
		
5) In Terminal,

	uv tool install --upgrade ollmcp
	
6) Register and verify the ZK MCP Server. In Terminal,

	ollmcp mcp add zk-doc -- /root/run-zk-mcp.sh
	
	ollmcp mcp list
	
7) Try it:

	ollmcp --model qwen2.5-coder:1.5b
	
8) Test with Human-in-the-Loop Confirmation. Try this prompt:

	Search the ZK documentation for how to bind a Listbox model in MVVM in ZK 10.


Remote (more powerful) models with openrouter and a self-hosted gateway
=======================================================================

IMPORTANT: I was unable to configure the chatbot's plugin 
		(https://psychic-coder.github.io/eclipse-chatbot-plugin2/) 
		in Eclipse. For some reason, the settings were not shown 
		in Window → Preferences.

1) Register in openrouter.ai and get an API key.

2) Deploy freellmpool on Your Laptop:

	uv tool install freellmpool
	
	Start the Gateway: Run freellmpool proxy --port 8080
	Leave this terminal running. Your local endpoint is now http://localhost:8080/v1.
	
	Add OpenRouter Key: To make OpenRouter models available through the pool, 
	set your key as an environment variable before starting the proxy:
	
	echo 'export OPENROUTER_API_KEY="sk-or-..."' >> ~/.bashrc
	source ~/.bashrc
	
3) Install Chatbot Assistant in Eclipse:

	In Eclipse, go to Help → Install New Software...

	Click Add... and enter this update site: 
	https://psychic-coder.github.io/eclipse-chatbot-plugin2/.

	Select Chatbot Assistant, complete the wizard, and restart Eclipse. 
	Open the view via Window → Show View → Other... → Chatbot Assistant.
	
4) Configure Chatbot Assistant:

	In the plugin's settings (gear icon or Window → Preferences):

    	Provider/API Type: OpenAI (or OpenAI-Compatible)

    	Base URL: http://localhost:8080/v1

		API Key: anything (this is ignored by freellmpool)

		Model Name: qwen/qwen3-coder:free (the exact free model ID for OpenRouter)
		
5) Test with Your Eclipse Project Code:

    Open a Java class from soberano in the editor.

    Select a specific method (avoid whole-class selection to prevent context limits).

    In the Chatbot Assistant, ask: "Explain the selected code."

    The request flows: Chatbot → freellmpool (localhost:8080) → OpenRouter → Qwen model. 
    freellmpool automatically handles routing and failover.
    

Remote (more powerful) models with openrouter and AI Peon
=========================================================

1) Window → Preferences → Peon AI.

	Fill the four fields exactly as follows:
		
		Provider:	OPEN_AI
		
		Model:	nvidia/nemotron-3-ultra-550b-a55b:free
		
		Base URL:	https://openrouter.ai/api/v1
		
		API Key:	Your sk-or-... OpenRouter key

		The direct OpenRouter configuration is the simplest path if you are comfortable 
		with the key sitting in Peon AI's preferences. The freellmpool configuration 
		routes through your local gateway, which keeps the OpenRouter key out of Eclipse 
		entirely—but you must ensure freellmpool has the OPENROUTER_API_KEY available 
		in its environment when you start it, or it will not be able to forward the request.
